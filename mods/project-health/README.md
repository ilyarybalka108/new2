# project-health

Мод для Claude Code: боковая панель «Здоровье проекта». После каждого хода, в котором Claude правил исходники (`Edit`, `Write`, `NotebookEdit`), мод сам запускает `npm run typecheck`, `npm run lint` и `npm test` в папке сессии и показывает результат: зелёную или красную отметку на каждую проверку, время выполнения и первые строки ошибок. Итог дублируется в статус-строке под промптом, а при поломке приходит тост.

## Установка

В терминальной сессии Claude Code:

```
/plugin install project-health --marketplace ilyarybalka108/new2
```

Подтвердить добавление маркетплейса (`y`) и выбрать область установки. Для разработки без установки: `claude --plugin-dir mods/project-health`.

## Использование

- `/health` — запустить все проверки сейчас и вывести отчёт в чат.
- `/health open` — только открыть панель.
- В панели: клавиша `r` запускает проверки вручную.

## Требования

В `package.json` проекта должны быть скрипты `typecheck`, `lint` и `test`. Каждая проверка ограничена тремя минутами.
